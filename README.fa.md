# CertScan

**ابزار کنسولی فقط‌خواندنی که گواهی‌های یک پوشه را بررسی می‌کند و همهٔ خطرها را به رنگ قرمز نشان می‌دهد.**

[English](README.md)

## هدف

نصب یک Root CA آن را به «لنگر اعتماد» (Trust Anchor) تبدیل می‌کند. اگر گواهی افزونهٔ **Name Constraints** نداشته باشد، هر کسی که کلید خصوصی آن را دارد می‌تواند برای هر دامنه‌ای گواهی صادر کند که سیستم شما به آن اعتماد می‌کند، و این یعنی امکان شنود بی‌صدای TLS. CertScan پیش از نصب، فایل گواهی را بررسی می‌کند و نشان می‌دهد چه اختیاراتی دارد.

## امکانات

- **کشف خودکار:** فایل‌های `.cer .crt .der .pem .p7b .p7c .spc .pfx .p12` در مسیر فعلی (یا پوشه‌ای که بدهید) پیدا می‌شوند. فایل PEM حاوی چند گواهی هم پشتیبانی می‌شود.
- **بررسی جداگانهٔ هر گواهی** با نوار پیشرفت، حکم نهایی، امتیاز ۰ تا ۱۰۰ و کارت ریسک مخصوص خودش.
- **خطرها قرمز هستند:** `CRITICAL` سفید روی قرمز، `HIGH` و `MEDIUM` قرمز، `LOW` قرمز تیره. رنگ سبز یعنی چیزی پیدا نشد.
- **جزئیات کامل در صورت درخواست:** از منوی تعاملی، هویت، اعتبار، اثرانگشت‌ها، کلید و امضا، محدودیت‌ها، EKU، Name Constraints، SAN، CRL/AIA و همهٔ افزونه‌ها نمایش داده می‌شوند و فیلدهای پرریسک قرمز می‌شوند.
- **بررسی Trusted Store:** مشخص می‌کند گواهی همین حالا در Trusted Root کاربر جاری یا LocalMachine نصب هست یا نه.
- **فقط‌خواندنی و آفلاین:** چیزی نصب، تغییر یا ارسال نمی‌شود.
- **بدون وابستگی NuGet:** تجزیهٔ ASN.1 با یک DER reader داخلی انجام می‌شود.

## پیش‌نیاز

- برای ساخت: .NET SDK 8.0 یا بالاتر (پروژه برای `net48` و `net8.0` تنظیم شده است)
- اجرا روی .NET Framework 4.8 یا .NET 8. ابزار برای ویندوز نوشته شده است.

## ساخت

```bash
git clone https://github.com/Shahabs2004/CertScan.git
cd CertScan
dotnet build -c Release
```

اگر فقط یک فریم‌ورک لازم دارید، دیگری را از `<TargetFrameworks>` در `CertScan.csproj` حذف کنید.

## استفاده

```text
CertScan [folder] [options]
```

| گزینه | توضیح |
|---|---|
| `folder` | پوشه‌ای که باید بررسی شود (پیش‌فرض: پوشهٔ فعلی) |
| `-r`, `--recursive` | شامل زیرپوشه‌ها |
| `-d`, `--details` | چاپ جزئیات کامل همهٔ گواهی‌ها و خروج، بدون منو |
| `--no-anim` | خاموش کردن انیمیشن‌ها |
| `--ascii` | استفاده از کاراکترهای ASCII برای کنسول‌ها یا فونت‌های قدیمی |
| `-h`, `--help` | راهنما |

```bash
CertScan                      # بررسی پوشهٔ فعلی
CertScan C:\certs -r          # بررسی یک پوشه و زیرپوشه‌ها
CertScan --details --no-anim  # گزارش کامل، مناسب هدایت به فایل
```

### منوی تعاملی

| کلید | عملکرد |
|---|---|
| `D` | جزئیات کامل یک گواهی (شماره را می‌پرسد) |
| `A` | جزئیات کامل همهٔ گواهی‌ها |
| `L` | فهرست ریسک همهٔ گواهی‌ها |
| `S` | جدول خلاصه |
| `Q` / `Esc` | خروج |

### کد خروج

| کد | معنی |
|---|---|
| `0` | ریسک قابل‌توجهی نیست |
| `1` | ریسک کم یا متوسط |
| `2` | ریسک بالا یا بحرانی (یا وجود کلید خصوصی در فایل PEM) |
| `3` | خطا (مثلاً پوشه پیدا نشد) |

## چه چیزهایی بررسی می‌شود؟

| حوزه | نمونه‌ها |
|---|---|
| Trust Anchor | Root بدون Name Constraints (بحرانی)، CA میانی بدون Name Constraints، گواهی Self-signed |
| Name Constraints | غیر Critical بودن، فقط Exclude، اجازهٔ همهٔ DNSها |
| Basic Constraints / Key Usage | نبودن `pathLen`، CA بدون `keyCertSign`، گواهی نهایی با حق امضای گواهی |
| Extended Key Usage | CA بدون محدودیت، Code Signing، Smart-card Logon و KDC، Client Auth، S/MIME |
| امضا و کلید | MD5/MD2 (بحرانی)، SHA-1، RSA زیر ۲۰۴۸ بیت، EC زیر ۲۵۶ بیت، DSA |
| اعتبار | منقضی‌شده، هنوز معتبر نشده، نزدیک به انقضا، طول عمر بسیار زیاد |
| ساختار | نسخهٔ v1، سریال کوتاه، نبودن CRL/OCSP |
| نام‌ها | نبودن SAN، Wildcard روی کل TLD |
| افشای کلید | کلید خصوصی در PFX با رمز خالی (بحرانی)، کلید خصوصی داخل فایل PEM |
| محیط | نصب‌بودن گواهی در Trusted Root همین سیستم |

Root بدون Name Constraints برای CAهای عمومی ممیزی‌شده (مثل DigiCert) عادی است، اما برای صادرکنندهٔ ناشناس پذیرفتنی نیست. ابزار فقط توانایی گواهی را گزارش می‌کند و قضاوت با شماست.

## محدودیت‌ها

- ابزار **فایل‌های گواهی** را بررسی می‌کند و زنجیرهٔ یک سرور زنده را اعتبارسنجی نمی‌کند.
- فایل‌های PKCS#12 دارای رمز قابل بررسی نیستند (فقط رمز خالی امتحان می‌شود) و با یک یادداشت رد می‌شوند.
- نتایج، ارزیابی‌های اکتشافی بر پایهٔ محتوای خود گواهی هستند. نتیجهٔ «تمیز» اعتمادپذیری را تضمین نمی‌کند و نتیجهٔ قرمز الزاماً به معنای بدخواهی نیست. پیش از نصب هر Root، اثرانگشت SHA-256 را از یک کانال مستقل تأیید کنید.
- رابط کنسول انگلیسی است، چون کنسول‌ها متن فارسی را درست نمایش نمی‌دهند.
